# Помощник по учёбе

Приложение для телефона: пары на завтра, задания, остаток часов по предметам, оценки и средний балл, таймер учёбы.
Одна страница без сборки. Данные хранятся в браузере (localStorage).

## Запуск на телефоне через GitHub Pages
1. Загрузи все файлы в репозиторий.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Открой выданную ссылку на телефоне и добавь на главный экран («Добавить на экран «Домой»» / «Установить приложение»).

Данные остаются только на том устройстве и в том браузере, где ты их ввёл.
